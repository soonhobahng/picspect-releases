수천 장의 이미지를 스캔하여 콘텐츠 해시 기반으로 정확한 중복을 즉시 탐지합니다

PDF 문서에 포함된 모든 이미지를 포맷 감지 및 메타데이터와 함께 추출합니다

이미지 감사에 필요한 모든 것

학술 무결성 담당자, 학술지 편집자, 포렌식 감사관을 위해 설계되었습니다.

🔍

중복 탐지

SHA-256, 지각 해싱, 시각적 비교를 활용한 다단계 파이프라인. 크기 변경, 자르기, 재압축 후에도 중복을 찾아냅니다.

📄

PDF 이미지 추출

클릭 한 번으로 PDF 문서의 모든 내장 이미지를 추출합니다. JPEG, PNG 무손실 추출을 지원합니다.

⚖

오류 수준 분석 (ELA)

JPEG 압축 아티팩트를 분석하여 조작을 감지합니다. 변조된 영역이 ELA 시각화에서 밝은 점으로 나타납니다.

📋

복사-이동 탐지

블록 기반 DCT 매칭으로 단일 이미지 내 복사-붙여넣기 영역을 식별하고 시각적 오버레이로 강조 표시합니다.

📈

나란히 비교

슬라이더, 나란히 보기, 차이점 보기로 두 이미지를 비교합니다. RMSE 왜곡 지표로 유사/다름을 즉시 판정합니다.

📃

PDF 감사 보고서

플래그된 중복 이미지의 썸네일과 유사도 점수가 포함된 전문 감사 보고서를 자동 생성합니다.

사용 방법

1

폴더 또는 PDF 선택

분석할 이미지 폴더 또는 PDF 문서를 선택합니다.

2

문제 스캔

Picspect가 해싱, 지각적 비교, 시각적 검증의 다단계 분석을 수행합니다.

3

결과 검토

정확한 중복, 유사 쌍을 탐색하고 플래그된 이미지에 ELA 또는 복사-이동 탐지를 실행합니다.

4

보고서 내보내기

모든 분석 결과가 포함된 PDF 감사 보고서를 생성하여 검토 또는 제출할 수 있습니다.
